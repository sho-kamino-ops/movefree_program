演習1: 「良いプロンプト」と「悪いプロンプト」
あなたは新人プログラマーです。先輩が書いた以下のPythonコードの意味が分からず、AIに質問して理解を深めようとしています。

Python
def get_unique_users(user_list):
    return list(set(user_list))



「良いプロンプト」

役割設定
あなたは、経験豊富なベテランのプログラマーです。

 背景・文脈
私は新人プログラマーで、先輩が作成した以下のPythonコードの意味が分からない状況です。

先輩の作成コード
Python
def get_unique_users(user_list):
    return list(set(user_list))

指示
先輩のPythonコードの意味を理解するために、新人プログラマーでも理解出来るように解説して欲しい。

制約条件
専門的な用語はなるべく避けて欲しい
プログラマーに関わらず、誰が見ても分かるように

出力形式
それぞれのコードについて、コードの名称、コードの意味、このコードがない事による不具合を箇条書きでまとめてください。


「悪いプロンプト」
下記のコードについて教えて。

Python
def get_unique_users(user_list):
    return list(set(user_list))


演習2: アイデア出し

 役割設定
あなたは、プログラミング初心者向けにGit/GitHubを飽きずに
教える事が出来るプロのプログラミング講師です。

 指示
プログラミング初心者が、飽きずに楽しんで学習出来る

 制約条件

その時代の首都名、首都だった時の年号
